API tienda ADSO
API REST desarrolladaa con FastAPI y MySQL para la gestion de clientes, productos y pedidos.

DESCRIPCION
este proyecto implemneta una API para administrar una tienda, permitiendo:
* Gestion de clientes
* Gerstion de productos
* Registro de pedidos 
* Control de stock
* Cancelacion de pedidos
* Reportes de ventas
* Validaciones de integridad referncial

TECNOLOGÍAS UTILIZADAS
* Python
* FastAPI
* MySQL
